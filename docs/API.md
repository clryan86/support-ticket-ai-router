# API

- `POST /api/route` — classify and route one ticket
- `POST /api/route/batch` — route up to 200 tickets
- `GET /api/tickets` — routing history
- `POST /api/tickets/{id}/feedback` — record correction
- `GET /api/model` — classifier metadata
- `GET /api/metrics` — routing metrics
- `GET /healthz` — health/model version

Interactive documentation is available at `/docs`.
